    Лабораторная работа 2¶

    Тема¶

    Потоки, процессы и асинхронность в Python.

    Задача 1. Сумма чисел от 1 до 10 000 000 000 000¶

    Реализованы три программы:

    Подход Файл Механизм
    threading scripts/lab2/sum_threading.py Диапазон делится на части, каждая часть считается в отдельном потоке.
    multiprocessing scripts/lab2/sum_multiprocessing.py Диапазон делится на части, каждая часть считается отдельным процессом.
    asyncio scripts/lab2/sum_async.py Диапазон делится на асинхронные задачи, запускаемые через asyncio.gather.

    В каждой программе используется функция calculate_sum(start, end). Чтобы программа реально запускалась за разумное время, сумма каждого диапазона считается по формуле арифметической прогрессии, а не циклом по 10 триллионам чисел.

    Задача 2. Параллельный парсинг веб-страниц¶

    Реализованы три программы:

    Подход Файл Механизм
    threading scripts/lab2/parse_threading.py URL делятся между потоками.
    multiprocessing scripts/lab2/parse_multiprocessing.py URL делятся между процессами.
    asyncio + aiohttp scripts/lab2/parse_async.py URL загружаются конкурентно через aiohttp.

    Каждая программа содержит функцию parse_and_save или обертку над ней, загружает HTML, достает заголовок страницы и сохраняет результат в таблицу parsed_pages.

    Используемая база данных¶

    Используется PostgreSQL из лабораторной работы 1. Для хранения результатов парсинга добавлена таблица parsed_pages:

    • url - адрес страницы;
    • title - заголовок страницы;
    • status_code - HTTP-статус;
    • content_length - размер HTML;
    • parser_type - подход, которым выполнен парсинг;
    • error - текст ошибки, если страницу не удалось загрузить.

    Запуск¶

    Перед запуском программ нужно применить миграции:

    source .venv/bin/activate
alembic upgrade head

    Запуск задачи 1:

    python -m scripts.lab2.sum_threading
python -m scripts.lab2.sum_multiprocessing
python -m scripts.lab2.sum_async

    Запуск задачи 2:

    python -m scripts.lab2.parse_threading
python -m scripts.lab2.parse_multiprocessing
python -m scripts.lab2.parse_async

    Сравнение подходов¶

    Подход Ожидаемые особенности
    threading Удобен для сетевых запросов, но не ускоряет CPU-bound задачи из-за GIL.
    multiprocessing Подходит для CPU-bound задач, потому что процессы используют разные интерпретаторы Python.
    asyncio Хорош для большого количества операций ввода-вывода, например HTTP-запросов.

    Фактическое время выполнения выводится каждой программой в консоль.
