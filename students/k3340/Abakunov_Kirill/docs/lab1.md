# Лабораторная работа 1

## Тема

Разработка backend-платформы для поиска партнеров в проекты.

## Суть задания

Нужно было создать веб-платформу, которая помогает людям находить участников для совместной работы над проектами. Пользователи должны иметь возможность создавать профили, указывать навыки, опыт и интересы, искать других участников, создавать проекты, формировать команды и управлять задачами.

## Что реализовано

В работе реализовано серверное приложение на FastAPI. Пользователь может зарегистрироваться, войти в систему, создать профиль, добавить навыки, найти других пользователей по критериям, создать проект, команду и задачи.

Основной функционал:

- регистрация пользователей;
- вход и JWT-авторизация;
- получение информации о текущем пользователе;
- создание и редактирование профиля;
- добавление навыков к профилю;
- поиск профилей по тексту, навыкам, интересам и опыту;
- создание и просмотр проектов;
- создание команд;
- добавление участников в команды;
- создание задач проекта;
- изменение статуса и прогресса задач.

## Используемые технологии

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy ORM
- Alembic
- Pydantic
- JWT
- Docker Compose для локального PostgreSQL

## Модель данных

| Таблица | Назначение |
| --- | --- |
| `users` | Учетные записи пользователей: email, username, хэш пароля, активность. |
| `profiles` | Профили пользователей: ФИО, описание, опыт, интересы, проектные предпочтения. |
| `skills` | Справочник навыков. |
| `user_skills` | Связь many-to-many между профилями и навыками. Дополнительные поля: `level`, `years`. |
| `projects` | Проекты: цели, требования, ожидаемый результат, срок и статус. |
| `teams` | Команды, созданные для работы над проектами. |
| `team_members` | Связь many-to-many между командами и пользователями. Дополнительные поля: `role`, `status`, `joined_at`. |
| `project_tasks` | Задачи проекта: срок, исполнитель, статус и процент выполнения. |

## Связи

- `users` 1:1 `profiles`;
- `users` 1:N `projects`;
- `profiles` M:N `skills` через `user_skills`;
- `projects` 1:N `teams`;
- `projects` 1:N `project_tasks`;
- `teams` M:N `users` через `team_members`;
- `users` 1:N `project_tasks` как исполнитель задач.

## Основные эндпоинты

### Авторизация и пользователи

- `POST /auth/register` - регистрация пользователя.
- `POST /auth/login` - вход и получение JWT-токена через JSON.
- `POST /auth/token` - получение JWT-токена через Swagger OAuth2 форму.
- `GET /auth/me` - информация о текущем пользователе.
- `GET /auth/users` - список пользователей.
- `POST /auth/change-password` - смена пароля.

### Навыки и профили

- `POST /skills` - создание навыка.
- `GET /skills` - список навыков с поиском.
- `POST /profiles/me` - создание профиля текущего пользователя.
- `GET /profiles/me` - просмотр своего профиля.
- `PATCH /profiles/me` - обновление своего профиля.
- `POST /profiles/me/skills` - добавление или обновление навыка в профиле.
- `GET /profiles` - поиск профилей по тексту, навыку, интересу и опыту.
- `GET /profiles/{profile_id}` - просмотр профиля с вложенными навыками.

### Проекты и задачи

- `POST /projects` - создание проекта.
- `GET /projects` - список проектов с фильтрацией.
- `GET /projects/{project_id}` - просмотр проекта с задачами.
- `PATCH /projects/{project_id}` - обновление проекта.
- `DELETE /projects/{project_id}` - удаление проекта.
- `POST /projects/{project_id}/tasks` - создание задачи проекта.
- `PATCH /projects/{project_id}/tasks/{task_id}` - обновление задачи проекта.

### Команды

- `POST /teams` - создание команды для проекта.
- `GET /teams` - список команд с фильтрацией по проекту и навыкам участников.
- `GET /teams/{team_id}` - просмотр команды с участниками.
- `PATCH /teams/{team_id}` - обновление команды.
- `POST /teams/{team_id}/members` - добавление участника в команду.
- `PATCH /teams/{team_id}/members/{user_id}` - обновление роли или статуса участника.
- `DELETE /teams/{team_id}/members/{user_id}` - удаление участника из команды.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
docker compose up -d postgres redis
alembic upgrade head
uvicorn app.main:app --reload
```

Swagger-документация API:

```text
http://127.0.0.1:8000/docs
```
